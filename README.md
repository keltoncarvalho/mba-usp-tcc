# mba-usp-tcc
Script para reprodução do meu Trabalho de Conclusão de Curso do MBA USP/Esalq sobre Pobreza Multidimensional e Programa Bolsa Família

## Fonte de dados
Este projeto utiliza microdados da Primeira Visita de 2024 da Pesquisa Nacional por Amostra de Domicílios Contínua (PNAD) coletada pelo Instituto Brasileiro de Geografia e Estatística (IBGE). Os dados podem ser baixados dinamicamente pelo script através do pacote pnadium, estando sujeitos aos termos de licença originais da PNADc.

## Resumo do Projeto
Este projeto utiliza-se da metodologia Alkire Foster para identificar os pobres multidimensionais no Brasil em 2024, fazendo a decomposição segundo o recebimento do Bolsa Família. Utiliza-se um Modelo Linear Generalizado para investigar a associação entre receber o auxílio e a classificação como pobre multidimensional pelo Índice de Pobreza Multidimensional.
